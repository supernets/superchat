SuperChat IRC Gateway
Requires a WebSocket port (not 6667/6697)
WeeChat relay setup

You need WeeChat 2.9+ (4.1+ for the channel list), a domain pointing at the machine running WeeChat, and port 80 free while the certificate is issued.

1. Get a Let's Encrypt certificate:

sudo certbot certonly --standalone -d relay.example.com --register-unsafely-without-email

2. Create /etc/letsencrypt/renewal-hooks/deploy/weechat-relay so WeeChat gets a copy now and on every renewal (set your user and domain):

#!/bin/sh
U=youruser
L=/etc/letsencrypt/live/relay.example.com
D=/home/$U/.config/weechat/tls
mkdir -p $D
cat $L/privkey.pem $L/fullchain.pem > $D/relay.pem
chown -R $U: $D && chmod 600 $D/relay.pem
for f in /run/user/$(id -u $U)/weechat/weechat_fifo_* /home/$U/.cache/weechat/weechat_fifo_*; do
	if [ -p "$f" ]; then echo '*/relay tlscertkey' > "$f"; fi
done
sudo chmod +x /etc/letsencrypt/renewal-hooks/deploy/weechat-relay
sudo /etc/letsencrypt/renewal-hooks/deploy/weechat-relay

3. In WeeChat:

/secure set relay YOUR_PASSWORD
/set relay.network.password "${sec.data.relay}"
/set relay.network.websocket_allowed_origins ""
/relay tlscertkey
/relay add tls.weechat 9001
/save

4. Open port 9001/tcp in your firewall, then connect here with host relay.example.com, port 9001, SSL/TLS on, and your password.

Older than WeeChat 4.0: use ssl.weechat instead of tls.weechat. Config in ~/.weechat: change the D= path. Something already on port 80: use --webroot -w /var/www/html instead of --standalone.
